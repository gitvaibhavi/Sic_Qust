# SciQuest - A Science Quiz Game
📚 An interactive quiz game to enhance scientific knowledge!

## 📝 Overview
SciQuest is a Flutter-based mobile quiz application designed to test and enhance users' scientific knowledge. 

The game includes multiple-choice questions from various fields of science, making learning fun and engaging.

## 🚀 Features
✅ Science-Based Quiz – Focused on biology, physics, chemistry, and more

✅ Multiple Difficulty Levels – Easy, Medium, Hard categories

✅ Hints & Explanations – Get explanations after answering questions

✅ Score Tracking – View your progress and improve your knowledge

✅ Biology-Themed UI – Unique design with science-related icons

✅ Offline Support – Play without an internet connection

## 🛠️ Tech Stack
- Flutter – Frontend development
- Dart – Programming language
- Firebase (Optional) – For user authentication and leaderboard (if implemented)
